# H5 · Readiness decision boundaries

**Complete by restriction and an explicit no-go for prescriptions.** The [H2-A review](../h2a/review.json) and [dated rule audit](../h2a/rule-audit.json) cover the exact sleep thresholds, energy/pain/fatigue branches, nine ratio cells, rounding, caution overrides and step-focus note. Their physiological accuracy and decision value are not established.

| Current rule | Intended evidence target | Present decision |
| --- | --- | --- |
| Sleep under 5 or 7 hours | Next-session performance under matched timing | Exact cutoffs unvalidated; retain as illustrative categories |
| Energy, soreness, pain and weekly fatigue | Prospectively observed task change; separate adverse-use review | Reflection only; no injury risk or clearance score |
| Nine set-ratio cells and rounded ranges | Benefit and harm from acting on a set recommendation | No-go; no optimal or safe set target established |
| High steps with leg focus | Added predictive information beyond usual workload | Context note only; no automatic calorie or readiness penalty |
| Full-session/rest labels | Correct user interpretation | Replace action claims with entered-signal descriptions |

The browser now says “Fewer caution signals entered”, “Mixed signals entered” or “Signals need attention”. Set-band arithmetic sits inside an explicitly illustrative disclosure. The adjacent limitation remains visible. The legacy SDK fields and deterministic numbers remain available for compatibility with their existing disclaimer; their names do not authorize prescriptions.

The [prospective protocol](protocol.json) fixes outcomes, simple comparators, participant/time isolation and adverse-use boundaries before data collection. It is not a completed experiment. New suitable prospective evidence, followed by a separate decision-benefit study, can reopen this restriction. Reviewer: maintaining agent; no clinical validation or independent duplicate review claimed.
