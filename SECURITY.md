# Security policy

METRON has no backend, analytics, remote API calls or production user data storage. Still, client-side security, dependency integrity and build workflows matter.

**Please do not report exploitable vulnerabilities in public issues.** Use GitHub's private vulnerability reporting feature (Repository → Security → Report a vulnerability) when enabled, or contact maintainers through an agreed private GitHub channel. Include reproduction steps and affected versions. We will acknowledge and triage responsibly; no response SLA is promised at this stage.

Supported version: the latest tagged release and `main` (pre-release development). Never include private measurements or personal details in a security report unless essential and explicitly consented to.
