ⓘHow is this calculated?⌄

TDEE ≈ baseline + walking + gym. We estimate resting expenditure with Mifflin–St Jeor (or Cunningham if you opt in), use a sedentary baseline multiplier, then add incremental activity.

Walking assumes level terrain and estimated stride length. Workout intensity is a whole-session MET approximation. Steps during treadmill workouts can be counted twice—adjust accordingly.
